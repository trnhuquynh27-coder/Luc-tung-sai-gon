# Lục Tung Sài Gòn

Website tĩnh một trang (index.html), tự chứa toàn bộ ảnh/CSS/JS, không cần build.

## Deploy lên Netlify
1. Upload toàn bộ nội dung thư mục này (hoặc đẩy vào) một repository trên GitHub.
2. Trên Netlify: "Add new site" → "Import an existing project" → chọn repository đó.
3. Build command: để trống. Publish directory: để trống hoặc "/" (vì chỉ có index.html ở gốc).
4. Deploy — Netlify sẽ tự nhận index.html làm trang chủ.
