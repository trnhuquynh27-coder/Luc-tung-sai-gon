# Lục Tung Sài Gòn – Tour tự thiết kế

Website demo cho bài tập nhóm môn Marketing du lịch (CASE 1 – Lữ Hành Sài Gòn).

Tính năng: ba tầng sản phẩm, thư viện ảnh, tour đề xuất có giá tham khảo, công cụ tự thiết kế tour (ngày đi, đổi giờ), đăng nhập/đăng ký (demo), trợ lý ảo, liên hệ và bản đồ văn phòng.

Cách xem: mở `index.html` bằng trình duyệt (cần Internet để hiện bản đồ và font).
Cách đăng web: kéo thả cả thư mục hoặc file zip lên Netlify Drop.

Lưu ý: giá tour là giá tham khảo minh họa; sửa trong mảng TOURS ở cuối file index.html.
